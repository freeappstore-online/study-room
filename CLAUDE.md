# study-room

A free Study Room app on FreeAppStore.

- Subdomain: `study-room.freeappstore.online`
- Dev: `pnpm install && pnpm dev`
- Build: `pnpm build`
- Typecheck: `pnpm typecheck`
- Deploy: `git push origin main` (auto-deploys via GitHub Actions)

Study Room is a quiet shared Pomodoro room for focused study sessions. It includes room presence, host-controlled focus/break sessions, an async discussion board, saved posts, and Markdown export.

Free, MIT-licensed, no tracking.

For platform conventions, read `SKILLS.md`:
https://raw.githubusercontent.com/freeappstore-online/freeappstore/main/SKILLS.md
